# Technology icons

`src/components/portfolio/tech-icon-paths.json` contains selected SVG path data from [Simple Icons](https://github.com/simple-icons/simple-icons), npm release **16.36.0**, under [CC0 1.0](simple-icons-CC0.md).

Icons and brand colors (`tech-icon-colors.json`) are bundled locally. They use the site's neutral color at rest and the technology's brand color on hover or focus within its tile. Black/white marks follow the theme; deep colors have a lighter dark-theme variant. Technology names remain visible text. Java, SSH, VPS Hosting, and unrecognized technologies use generic Lucide icons under the existing `lucide-react` dependency. Brand icons identify technologies and do not imply endorsement.
